# NoSQL & Mongo DB

## What is MongoDB?

MongoDB is a **NoSQL** database. It is:

* Open-source
* Cross-platform
* Document-oriented

MongoDB is designed to store data in flexible, JSON-like documents, making it ideal for handling unstructured or semi-structured data.

It offers:

* High performance
* High availability
* Automatic scaling

***

## What is a NoSQL Database?

A **NoSQL database** provides a mechanism for storing and retrieving data that does not rely on the tabular structure of relational databases.

**Key characteristics:**

* Does **not use tables** for storing data
* Ideal for **big data** and **real-time web applications**
* Data is often stored in document, key-value, wide-column, or graph structures

***

### Advantages of NoSQL

* ✅ Supports powerful query languages
* ⚡ Offers fast performance
* 📈 Enables horizontal scalability (e.g., sharding across nodes)

***

## Common MongoDB Data Types

MongoDB supports the following data types for storing values inside documents:

* `String`
* `Integer`
* `Boolean`
* `Double`
* `Array`
* `Object`
* `Date`

These types allow for complex and nested data structures, enabling flexible schema design.
