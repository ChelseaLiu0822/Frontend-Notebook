# 🖼️ CSS Layout

## Box Model

The **CSS box model** is a foundational concept in web design. It consists of:

* **Content**: The actual content (text, image, etc.)
* **Padding**: Space between content and border (inside the element)
* **Border**: The outer edge of the element
* **Margin**: Space outside the border (separates elements)

## Float vs Flexbox

#### Float (Old Method)

```css
float: left; /* or right */
clear: both; /* used to clear floats */
```

{% embed url="https://codepen.io/ChelseaLiu0822/embed/EaabqNy?default-tab=html,result" %}

#### Flexbox (Modern CSS3 Method)

```css
display: flex; /* applies to parent */
```

> When `display: flex` is applied to a parent container, its child elements are arranged in one row by default.
